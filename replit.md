# Luxurious Homes — Dubai Real Estate Website

A marketing website for a Dubai executive-living real estate brand, built with TanStack Start, React 19, Tailwind CSS v4, and shadcn/ui.

## Stack

- **Framework**: TanStack Start (SSR + file-based routing)
- **UI**: React 19 + shadcn/ui (Radix UI primitives) + Tailwind CSS v4
- **Forms**: React Hook Form + Zod
- **Build**: Vite 8 + Bun
- **Config wrapper**: `@lovable.dev/vite-tanstack-config`

## Running the app

```bash
bun run dev   # starts dev server on port 5000
```

The workflow **"Start application"** runs this automatically.

## Routes

| Route | Page |
|---|---|
| `/` | Home (Hero, Highlights, Featured Properties, CTA) |
| `/properties` | Full property listing with filters |
| `/gallery` | Photo gallery |
| `/why-us` | Brand value proposition |
| `/contact` | Contact form |
